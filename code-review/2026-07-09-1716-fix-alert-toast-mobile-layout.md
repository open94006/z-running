# fix(ui): 修正 Alert toast 在手機版的定位與寬度

## 變更目的與背景

先前 Alert toast 固定使用 `top-4 right-4 max-w-sm w-full`，在手機版會偏向右側且寬度行為不夠直覺，容易造成左右留白不一致。

---

## 主要修改檔案與模組

| 檔案                                     | 說明                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------- |
| `client/src/components/AlertContext.tsx` | 將 toast 容器改為手機版 `inset-x-4`，桌面版維持 `right-4`，並調整寬度類別 |

---

## 核心邏輯調整說明

- 手機版改用 `inset-x-4`，讓提示訊息左右各保留一致間距。
- 桌面版透過 `sm:left-auto sm:right-4 sm:max-w-sm` 維持原本右上角浮動樣式。
- `w-full` 改為 `w-auto`，避免在手機版搭配 `inset-x-4` 時產生不必要的寬度衝突。

---

## 測試或驗證方式與結果

- 執行 `cd client && npm run build`。
- 結果：建置成功，TypeScript 與 Vite 打包皆通過。

---

## 可能影響範圍與注意事項

- 只影響 Alert / Confirm 浮層的 toast 容器版位，不涉及資料流或互動邏輯。
- 若未來再調整 toast 動畫或最大寬度，需一併檢查手機與桌面斷點表現。
